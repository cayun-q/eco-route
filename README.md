# Leaflet Map

A minimal Vite app with a basic HTML boilerplate that loads [Leaflet](https://leafletjs.com/) from the CDN and shows an OpenStreetMap view centered on London.

## Run locally

```bash
npm install
npm run dev
```

Open the URL printed in the terminal (default port is set in `package.json` / the Vite config).

## Stack

- Vite (dev server)
- Leaflet 1.9.4 via unpkg CDN (CSS + JS in `index.html`)
